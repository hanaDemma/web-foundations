
# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to quickly create, organize, search, and delete notes. Notes can be categorized as Personal, Work, or Study, and they are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

* Add notes with a maximum of 200 characters
* Choose a category: Personal, Work, or Study
* Display notes as organized cards
* Show the date and time when each note was created
* Search notes using case-insensitive search
* Delete individual notes
* Clear all notes
* Validate empty notes
* Validate notes longer than 200 characters
* Display the total number of notes
* Save notes using browser localStorage
* Responsive design for desktop and mobile screens
* Category-based styling for Personal, Work, and Study notes

## How to Run

1. Clone or download this repository.
2. Open the `quicknotes-app` folder in VS Code.
3. Open `index.html` using a browser or VS Code Live Server.
4. Start adding and managing your notes.

No additional installation or dependencies are required.
