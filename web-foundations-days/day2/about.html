About QuickNotes

QuickNotes is a simple app for jotting down ideas, reminders and to-dos before they slip away. It is designed to be fast and distraction-free, so you can spend your time thinking instead of formatting.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and your note text.
  3. Save the note; it appears in your notes list.
  4. Click any note in the list to edit or delete it.

Features

  • Create notes instantly
  • Edit and delete notes
  • Search through all your notes
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search notes
